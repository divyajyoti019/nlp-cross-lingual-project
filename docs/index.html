Cross-lingual question answering · Research demo

Policy answers with evidence attached.

IndicRAG-QA searches National Education Policy 2020 passages for questions asked in English, Hindi, or Hinglish. It returns source evidence with each answer and can abstain when the match is weak.

A question becomes a traceable answer.

The system ranks policy passages, checks the best score against a threshold, then selects an evidence sentence or abstains. Citations let readers inspect the retrieved text.

BM25

Ranks passages by query-word overlap. A fast lexical baseline.

Character TF-IDF

Compares character n-grams to handle spelling and word-form variation.

LaBSE dense

Uses multilingual sentence embeddings to find meaning across languages.

Hybrid

Combines normalized lexical matching with LaBSE similarity.

Small benchmark, measured carefully.

Each method’s answerability threshold was selected on the 12-question development split and applied unchanged to the 33-question test split.

How to read this: LaBSE retrieved the most annotated evidence in the top five, while character TF-IDF had the highest answerability F1 on this split. The benchmark covers only 30 starter passages and 33 test questions; these results do not establish general performance. The optional expanded corpus has not been evaluated against a matching test set.

Interactive Python application

Try the app or run it locally.

The interactive app is publicly hosted on Streamlit Community Cloud. Open it to ask questions and inspect citations, or use the commands below to run the same app from the source repository.

Open the live IndicRAG-QA app
git clone https://github.com/divyajyoti019/nlp-cross-lingual-project.git
cd nlp-cross-lingual-project
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
